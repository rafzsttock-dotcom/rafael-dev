# Deploy KODO / Rewardex + Telegram (MadelineProto, multi-akun)

## 1. Siapkan API Telegram
Daftar di https://my.telegram.org -> API development tools -> catat api_id & api_hash.

## 2. Di VPS - isi .env
cd /path/ke/reward-promotion
cp .env.example .env    # kalau belum ada
nano .env
# isi: DOMAIN, ADMIN_USERNAME, ADMIN_PASSWORD, TELEGRAM_API_ID, TELEGRAM_API_HASH, TELEGRAM_SERVICE_SECRET

## 3. Build image
sudo docker compose build

## 4. Login akun Telegram (SEKALI per akun, interaktif)
# Akun inilah yang mengirim OTP ke user. Bisa lebih dari satu (multi-akun, menyebar beban).
sudo docker compose run --rm telethon php login.php akun1
#   -> masukkan nomor HP akun (+62...), lalu kode dari Telegram, lalu password 2FA bila ada.
# Tambah akun lain (opsional):
sudo docker compose run --rm telethon php login.php akun2
# Sesi tersimpan di ./data/tg/akun1.madeline dst (persisten).

## 5. Jalankan
sudo docker compose up -d --build
sudo docker compose ps
sudo docker compose logs -f telethon --tail=50   # harus "akun aktif: @..." dan "listening"

## 6. Cek
curl -sI https://rewardex.site | head -3
# Status Telegram service (dari dalam VPS):
#   docker compose exec telethon sh -c 'wget -qO- --header="X-Service-Secret: $TELEGRAM_SERVICE_SECRET" http://localhost:8090/status'

## Kemampuan MadelineProto (dipakai sistem)
- Login via NOMOR HP (import kontak) maupun @username.
- Kirim OTP ke user (messages.sendMessage).
- Cek member channel (channels.getParticipant) & verifikasi start bot/join.
- Multi-akun: taruh beberapa sesi di ./data/tg, beban kirim dirotasi otomatis.

## Catatan risiko
- Akun userbot = akun Telegram asli. Jangan spam OTP; bisa kena limit/banned.
- Resolve via nomor hanya berhasil bila privasi target mengizinkan "cari lewat nomor".
- Simpan folder ./data/tg seperti password (berisi sesi login).
