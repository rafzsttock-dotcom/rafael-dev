# Deploy KODO Rewards + Telethon

## 1. Siapkan kredensial Telegram (laptop)
pip install telethon
python telegram-service/make_session.py
# copy TELEGRAM_SESSION yang dicetak

## 2. Di VPS — isi .env
cd /path/ke/reward-promotion
cp .env.example .env
nano .env
# isi: DOMAIN, ADMIN_*, TELEGRAM_API_ID, TELEGRAM_API_HASH, TELEGRAM_SESSION, TELEGRAM_SERVICE_SECRET

## 3. Build & jalan
sudo docker compose down
sudo docker compose up -d --build
sudo docker compose ps
sudo docker compose logs -f telethon --tail=50
sudo docker compose logs -f app --tail=50

## 4. Cek
curl -sI https://rewardex.site | head -3
# Admin > Pengaturan > Cek status Telethon

## Catatan risiko
- Telethon = akun USER Telegram, bukan bot. Jangan spam OTP.
- Simpan TELEGRAM_SESSION seperti password.
- Privacy user bisa menolak pesan dari non-kontak — minta user izinkan / add kontak akun pengirim.
