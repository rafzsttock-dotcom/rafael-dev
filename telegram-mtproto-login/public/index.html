Telegram MTProto Login

Tool pribadi untuk login akun Telegram milik sendiri via MTProto dan menyimpan StringSession terenkripsi secara lokal.

Akses Tool

1. Nomor Telepon

2. Kode OTP

Kode dikirim lewat Telegram (pesan "Telegram"), bukan SMS kalau akun sudah pernah pakai Telegram.

3. Password 2FA

Akun ini punya verifikasi dua langkah, isi password cloud password-nya.
