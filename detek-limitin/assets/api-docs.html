DetekLimitin API

REST API untuk Cek Bio, Detect OTP Status, dan manajemen API Key

Hanya tersedia untuk user Premium

Autentikasi

Semua endpoint (kecuali /api/docs dan /api/generate-key) butuh API Key.

// Pilih salah satu cara
Header:      X-API-Key: dl_xxxxxxxxxxxxxxxx
Query param: ?api_key=dl_xxx
Request body: "api_key": "dl_xxx"
Rate limit: 30 request per menit per API Key. Melebihi limit → HTTP 429.

Base URL

http://your-server:5055

Ganti dengan domain atau IP server kamu.

Endpoints

GET /api/docs

Dokumentasi JSON ini. Tidak butuh autentikasi.

POST /api/generate-key

Generate atau regenerate API Key. Butuh akun Premium. Jika sudah punya key, key lama langsung tidak berlaku.

Request Body
{ "telegram_id": 123456789 }
Response 200
{
  "success": true,
  "api_key": "dl_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "regenerated": false,
  "message": "Simpan API Key ini — hanya ditampilkan sekali. Jangan bagikan ke siapapun."
}
Errors
KodePenyebab
400telegram_id kosong atau bukan angka
403User belum atau sudah tidak Premium
404User tidak ditemukan (belum pernah /start bot)

DELETE /api/revoke-key

Revoke API Key aktif. Setelah ini key tidak bisa dipakai lagi.

Header
X-API-Key: dl_xxx
Response 200
{ "success": true, "message": "API Key berhasil di-revoke." }

GET /api/sessions

Status sesi WhatsApp yang terhubung ke akun kamu.

Response 200
{
  "success": true,
  "status": "CONNECTED",
  "ready": true,
  "sessions": [
    { "sessionId": 1, "phone": "628123456789" }
  ],
  "hint": "Sesi aktif. Siap untuk Cek Bio."

Jika ready: false, connect WA dulu lewat bot Telegram sebelum pakai /api/cek-bio.

Cara Dapat API Key

  1. Beli Premium lewat bot Telegram (/start → Beli Premium)
  2. Panggil POST /api/generate-key dengan telegram_id kamu
  3. Simpan API Key yang diberikan — tidak bisa dilihat lagi
  4. Kalau lupa / mau ganti, panggil endpoint yang sama lagi (key lama langsung tidak berlaku)

Error Codes

KodeArti

401API Key tidak ada atau tidak valid
403Belum Premium atau Premium sudah kadaluarsa
404User tidak ditemukan
429Rate limit (30 req/menit per API Key)
500Server error
503Layanan tidak tersedia (sesi WA belum aktif)
504Gateway timeout
