DetekLimitin API

REST API untuk Cek Bio, Detect OTP, dan Limitin

API Key wajib beli Premium

Autentikasi

Semua endpoint (kecuali docs & generate-key) butuh API Key.

Header: X-API-Key: dl_xxxxxxxxxxxxxxxx
atau query: ?api_key=dl_xxx
atau body: "api_key": "dl_xxx"
API Key hanya bisa digenerate setelah user beli Premium lewat bot Telegram.

Base URL

http://localhost:5055/api

Ganti dengan domain / IP server kamu.

Endpoint

GET /api/docs

Dokumentasi ini (JSON).

POST /api/generate-key

Generate API Key baru. User harus sudah Premium.

{
  "telegram_id": 31303135
}

Response:

{
  "success": true,
  "api_key": "dl_xxxxxxxx...",
  "message": "Simpan API Key ini. Hanya ditampilkan sekali."
}

GET /api/me

Info user dari API Key.

curl -H "X-API-Key: dl_xxx" http://localhost:5055/api/me

POST /api/cek-bio

Cek bio massal. Max 50 nomor. Butuh session WA aktif.

{
  "numbers": ["6281234567890", "6289876543210"],
  "mode": "simple"
}

POST /api/detect

Detect status / OTP endpoint.

{
  "number": "6281234567890",
  "method": "sms"
}

Method: sms, voice, wa

Cara Dapat API Key

  1. Buka bot Telegram → klik Beli Premium
  2. Bayar via QRIS
  3. Setelah aktif, call endpoint /api/generate-key dengan telegram_id kamu
  4. Simpan API Key yang dikasih

Rate Limit

30 request per menit per API Key.

Error Codes

CodeArti
401API Key missing / invalid
403Belum Premium
429Rate limit
400Bad request
500Server error
