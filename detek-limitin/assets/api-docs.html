DetekLimitin API

API untuk Cek Bio WhatsApp massal, Detect status OTP, dan manajemen API Key. Hanya tersedia untuk user Premium.

Beli Premium & Dapatkan API Key Lihat Endpoint
Base URL
https://api.wspro.id
Rate Limit
30 req / menit
Format
JSON
Autentikasi

Semua endpoint (kecuali /api/docs dan /api/generate-key) butuh API Key. Kirim lewat salah satu cara:

Header (direkomendasikan)
X-API-Key: dl_xxx
Query Parameter
?api_key=dl_xxx
Request Body
"api_key": "dl_xxx"
Rate limit: Melebihi 30 request per menit → server mengembalikan HTTP 429. Tunggu 60 detik sebelum retry.

POST /api/generate-key Publik ▼

Generate atau regenerate API Key. User harus sudah Premium. Jika sudah punya key, key lama langsung tidak berlaku.

Request Body
{ "telegram_id": 123456789 }
Response 200
{
  "success": true,
  "api_key": "dl_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "regenerated": false,
  "message": "Simpan API Key ini — hanya ditampilkan sekali."
}
Error Codes
KodePenyebab
400telegram_id kosong atau bukan angka

Cara Dapat API Key

  • Buka bot Telegram dan klik Beli Premium, lalu selesaikan pembayaran via QRIS.

  • Setelah Premium aktif, panggil POST /api/generate-key dengan telegram_id kamu.

  • Simpan API Key yang diberikan — tidak bisa dilihat lagi setelah ini.

  • Kalau lupa atau mau ganti, panggil endpoint yang sama lagi — key lama langsung tidak berlaku.
